Personal rclone Google Drive Integration

This website describes a personal setup of rclone, an open-source command-line tool used to manage files on cloud storage services, including Google Drive.

Purpose

This project is intended exclusively for personal use to synchronize, copy, back up, and manage files between a personal computer and the owner's Google Drive account.

How it works

Authentication is performed through Google's OAuth 2.0 authorization process. The user grants rclone permission to access Google Drive according to the permissions selected during configuration.

File operations are initiated by the user through rclone. This website does not provide file management services, collect Google Drive files, or process OAuth credentials.

Privacy

This is a personal project, not a public service. Google Drive data is accessed by the locally operated rclone software according to the permissions granted by the account owner.

For further information about data handling, please read the Privacy Policy.

Third-party software

rclone is an open-source project available at rclone.org. Google Drive is a service provided by Google. This personal project is not affiliated with or endorsed by Google or the rclone project.
